개인정보처리방침

배워언어는 한국어 사용자가 매일 짧은 루틴으로 외국어 문장을 학습할 수 있도록 돕는 로컬 우선 학습 앱입니다. 이 개인정보처리방침은 배워언어가 어떤 정보를 처리하고, 그 정보를 어떻게 보호하는지 설명합니다.

1. 개인정보의 처리 목적

배워언어는 다음 목적을 위해 필요한 범위에서 정보를 처리합니다.

  • 학습 콘텐츠 제공
  • 선택한 학습 언어와 앱 설정 유지
  • 완료한 레슨, 복습 일정, 정답/오답 횟수 등 학습 진행 상태 저장
  • 앱 기능 개선을 위한 오류 확인 및 사용자 문의 대응

2. 처리하는 개인정보 항목

배워언어 MVP는 회원가입, 로그인, 결제, 커뮤니티 기능을 제공하지 않으며 이름, 이메일 주소, 전화번호와 같은 직접 식별 정보를 앱 자체에서 수집하지 않습니다.

앱이 기기 안에 저장할 수 있는 정보는 다음과 같습니다.

  • 선택한 목표 언어
  • 완료한 레슨 ID
  • 문장별 시도 횟수와 오답 횟수
  • 문장별 복습 예정일
  • 마지막 학습일과 연속 학습일
  • 캐릭터, 튜토리얼 확인 여부 등 앱 설정

음성 기능을 사용하는 경우 다음 권한 또는 기기 기능이 사용될 수 있습니다.

  • 마이크 권한: 사용자가 직접 음성 입력 버튼을 눌러 발음 또는 문장 입력을 시도할 때 사용됩니다.
  • 텍스트 음성 변환(TTS): 학습 문장을 들려주기 위해 기기 또는 플랫폼의 음성 합성 기능을 사용합니다.
  • 음성 인식(STT): 사용자가 음성 입력을 선택한 경우 기기 또는 운영체제의 음성 인식 기능을 사용할 수 있습니다.

음성 인식과 음성 합성의 실제 처리 방식은 Android, iOS, Web 브라우저 등 사용 중인 플랫폼과 기기 설정에 따라 달라질 수 있습니다. 배워언어는 사용자가 입력한 음성 데이터를 자체 서버로 전송하거나 저장하지 않습니다.

3. 개인정보의 처리 및 보유 기간

학습 진행 상태와 설정은 사용자의 기기 로컬 저장소에 보관됩니다. 서버 계정과 동기화하지 않으므로 앱을 삭제하거나 기기에서 앱 데이터를 삭제하면 로컬에 저장된 학습 기록도 함께 삭제될 수 있습니다.

사용자가 앱 데이터 삭제, 앱 삭제, 운영체제 설정을 통한 권한 철회 등을 수행하면 해당 기기에서 관련 정보 처리가 중단되거나 삭제됩니다.

4. 개인정보의 제3자 제공

배워언어는 이용자의 개인정보를 외부에 판매하거나 제3자에게 제공하지 않습니다. MVP 기준으로 별도 백엔드 서버, 계정 시스템, 광고 네트워크, 분석 SDK를 사용하지 않습니다.

다만 사용자가 음성 인식 또는 음성 합성 기능을 사용할 때 운영체제, 브라우저, 기기 제조사 또는 해당 플랫폼의 서비스가 음성 처리를 수행할 수 있습니다. 이 경우 해당 처리는 각 플랫폼의 개인정보 처리방침과 기기 설정의 적용을 받습니다.

5. 개인정보 처리의 위탁

배워언어 MVP는 회원 정보 저장, 클라우드 동기화, 서버 분석, 광고 제공을 위한 개인정보 처리 위탁을 하지 않습니다.

향후 계정, 클라우드 동기화, AI 기능, 분석 기능 등 서버 또는 외부 서비스를 사용하는 기능이 추가될 경우, 수집 항목, 이용 목적, 보유 기간, 위탁 또는 제3자 제공 여부를 이 방침에 반영합니다.

6. 정보주체의 권리와 행사 방법

사용자는 언제든지 다음 권리를 행사할 수 있습니다.

  • 앱 내 설정 또는 운영체제 설정에서 마이크 권한 철회
  • 운영체제 설정에서 앱 데이터 삭제
  • 앱 삭제를 통한 로컬 학습 기록 삭제
  • 개인정보 처리와 관련된 문의

로컬 기기에만 저장되는 정보는 개발자가 원격으로 열람, 수정, 삭제할 수 없습니다. 사용자는 기기와 운영체제에서 제공하는 앱 데이터 관리 기능을 통해 직접 삭제할 수 있습니다.

7. 아동의 개인정보

배워언어는 아동을 대상으로 직접 식별 정보를 수집하는 계정 기능을 제공하지 않습니다. 보호자가 아동의 기기에서 앱 사용을 관리하는 경우, 운영체제의 보호자 통제 기능과 권한 설정을 함께 확인해 주세요.

8. 개인정보 보호를 위한 조치

배워언어는 다음 원칙에 따라 개인정보 처리를 최소화합니다.

  • 필수 로그인 없이 앱 사용 가능
  • 학습 기록은 기본적으로 기기 안에 저장
  • 앱 기능에 필요하지 않은 직접 식별 정보 미수집
  • 광고, 커뮤니티, 결제 기능 미도입
  • production API key를 앱에 직접 포함하는 AI 기능 미도입

10. 방침의 변경

이 개인정보처리방침은 앱 기능, 저장 방식, 외부 서비스 사용 여부가 변경될 때 함께 갱신될 수 있습니다. 중요한 변경이 있는 경우 앱 또는 배포 페이지를 통해 변경 내용을 안내합니다.
